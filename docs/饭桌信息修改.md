# 家长修改饭桌信息

## 使用方式

家长进入「我的 → 设置 → 饭桌信息 → 修改名称」，输入 1～40 个字后保存。普通成员可以查看饭桌名称，不能修改。目前支持名称，沿用上海时区和每周从周一开始的设置。

保存成功后刷新云端饭桌信息；家人进入「我的」或「今天」页面会读取最新名称。长名称自动换行。

## 异常处理

- 保存结果未知时保留原名称、版本和请求编号，冻结输入，点击「重试上次保存」确认同一操作，防止重复更新。
- 多人同时改名只接受一个相同版本的请求。冲突后显示最新名称并保留输入草稿，需要家长再次明确保存。
- 家长身份以云端事务检查为准；权限变化后刷新当前角色并停止允许编辑。
- 写入沿用文本内容检查和操作日志。名称、版本、回执和日志一起提交，失败时全部回滚。
