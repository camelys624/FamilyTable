# 家庭邀请实现与验收

更新日期：2026-10-12。扩展后端基线原先排除的邀请与加入流程，继续复用现有 14 个集合。当前实现覆盖生成/更换邀请码、输入邀请码加入、真实成员展示；成员退出、移除和管理员转移仍待后续实现。

## 使用方式

1. 管理员进入「我的」，点击「＋ 邀请」生成邀请码，再点击「复制」。
2. 家人打开同一个小程序，在首次进入页选择「加入家庭」，填写称呼和 8 位邀请码。
3. 加入成功后进入首页，双方在「我的」可查看真实成员，共享同一家庭的云端菜谱、菜单与冰箱。

默认有效期为 72 小时，页面以北京时间显示截止时间。管理员可以更换邀请码，旧码立即失效，已加入的成员不受影响。邀请码生成后仅在当前页面内存保留，重新打开页面会提示生成新码，不会自动使已有邀请码失效。每个家庭最多 20 位有效成员，每个账号只能加入一个家庭。

饮食偏好暂时仍保存在本机，投票与购物云端同步不属于此变更。

## 云端契约

所有身份均来自云函数服务端 OpenID，不接受客户端身份、家庭 ID 或角色。写操作要求 8～64 位 `requestId`，同参数重试重放结果，不同参数返回 `IDEMPOTENCY_CONFLICT`。

| 动作 | 请求 payload | 响应 data | 权限 |
| --- | --- | --- | --- |
| `family.current` | `{}` | `family, currentMember, members, invitation: {active, expiresAt}` | 有效家庭成员 |
| `family.invite` | `{expiresInHours?: 1..168}`，默认 72 | `{familyId, inviteCode, expiresAt}` | 当前家庭 owner |
| `family.join` | `{inviteCode, displayName}`，称呼 1～12 字 | `{family, member}` | 有效用户，有效邀请码，尚未加入其他家庭 |

邀请错误码：`INVITE_INVALID`（无效或已更换）、`INVITE_EXPIRED`、`FAMILY_FULL`；普通成员不能生成邀请码，返回 `FORBIDDEN`。

`families` 新增 `inviteCodeHash`（SHA-256）、`inviteExpiresAt`（服务端 Date）、`memberCount`（有效人数）。创建家庭初始化人数为 1；旧家庭首次生成邀请码时根据真实成员数补齐。邀请码由加密随机源生成，字符集排除 0/1/I/O。家庭和审计日志不保存邀请码明文；为恢复丢失响应，**管理员自己的成功幂等回执包含邀请码**，该集合必须禁止客户端直接读取。`family.current` 只返回有效期，不返回邀请码、哈希、用户 ID 或 OpenID。

新增非唯一索引 `families.idx_families_invite_status`：`inviteCodeHash asc, status asc`，兼容尚无邀请码的旧家庭。

事务内仅使用 `doc()`，事务外查询定位候选家庭/旧成员 ID，再在事务内重读并验证身份、成员状态、家庭状态、哈希和有效期。创建与加入均访问按用户 ID 生成的同一个成员文档，防止并发加入两个家庭。加入同时更新家庭人数，确保与更换邀请码和其他加入操作发生写冲突时整体重试；成员、用户称呼、幂等回执和审计日志一起提交。实现遵循 [CloudBase 事务限制](https://docs.cloudbase.net/database/transaction)。

## 部署与验收

1. 当前测试环境为 `cloud1-d3g26za1sf043b587`；本次仅更新 `family` 云函数，并部署上述索引，不切换生产环境。
2. 在云开发控制台确认 `users`、`families`、`family_members`、`idempotency_records`、`operation_logs` 及其他业务集合均禁止客户端直接读写（自定义安全规则 `{"read":false,"write":false}`）。云函数通过服务端权限访问数据库。
3. 上传并部署 `cloudfunctions/family`，勾选云端安装依赖；重新编译小程序。
4. 用两个真实微信账号验证：管理员生成并复制邀请码；未加入家庭的另一个账号输入邀请码加入；双方刷新「我的」均显示两位成员；新成员能查看同一份菜谱和冰箱。
5. 验证错误：无效码、过期码、旧码、普通成员尝试生成码、已加入其他家庭、重复提交与网络中断后重试。

自动测试涵盖事务只允许 doc、并发重试与回滚、单家庭关系、幂等冲突、角色校验、过期与轮换、真实成员显示、复制过期码拦截、页面重复提交和云端失败不回退示例数据。双账号真机测试不能由单个开发者工具登录替代。
