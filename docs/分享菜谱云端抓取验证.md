# 分享菜谱云端抓取验证（ROBB-38）

本阶段仅交付临时诊断函数 `recipeProbe`，供运营者在真实 CloudBase 开发环境验证用户提供的单页。没有实现菜谱导入、AI 整理或前端导入入口。**本文没有真实平台实测结果，三平台成功率、页面结构稳定性和首期支持范围仍待云端验证。**

## 部署和调用

1. 拉取本 PR 分支，在微信开发者工具打开仓库，核对目标环境为现有开发环境 `cloud1-d3g26za1sf043b587`。沿用项目 Node.js 云函数运行时，不切换环境、不修改现有业务函数。
2. 对 `cloudfunctions/recipeProbe` 选择“上传并部署：云端安装依赖”。函数仅依赖现有版本的 `wx-server-sdk`，其余使用 Node.js 内置模块。设置函数超时为 **30 秒**；抓取本身的总超时为 20 秒。
3. 仅在该诊断函数设置服务端环境变量 `RECIPE_PROBE_ENABLED=true`。未配置时返回 `FEATURE_UNAVAILABLE`。无需 AI 凭证，不增加集合、索引或 HTTP 触发器。
4. 用家庭管理员微信账号登录小程序，确认已完成家庭初始化。在该小程序的开发者工具控制台执行下面的调用，将 `shareText` 换为自己提供的真实分享文字。每次只提交一条分享，不批量请求。

```javascript
wx.cloud.callFunction({
  name: 'recipeProbe',
  config: { env: 'cloud1-d3g26za1sf043b587' },
  data: {
    action: 'probe.fetch',
    requestId: `probe_${Date.now()}`,
    payload: {
      sampleId: 'xcf-long-01',
      shareText: '替换为真实分享文字或 HTTPS 分享链接',
    },
  },
}).then(({ result }) => console.log(JSON.stringify(result, null, 2)))
```

`requestId` 需为 8–64 位字母、数字、下划线或连字符；`sampleId` 需为 1–48 位同类字符。分享文字最长 4096 字，仅允许一个不同的链接。普通家庭成员返回 `FORBIDDEN`，未登录返回 `UNAUTHENTICATED`。**直接在云函数控制台填入测试 JSON 通常没有小程序 OPENID，会被拒绝；不要通过 payload 伪造身份。** 函数每次重新验证有效用户、家庭成员和家庭状态，仅允许 `owner` 调用。

5. 保存返回的诊断摘要。`ok: true` 表示诊断执行完成，**不代表抓取或解析成功**。`ok: false` 是启用、身份、权限、参数或实例限流等调用错误。
6. 完成后移除 `RECIPE_PROBE_ENABLED` 或设为 `false`，关闭诊断。无需修改已有菜谱和家庭数据。

## 返回内容和限制

`data` 包含 `sampleId`、`measuredAt`、`environment`、`invocationId`、`platform`、`outcome`、`elapsedMs`、`hops` 和 `structure`。每一跳包含去掉查询参数和片段的 URL、HTTP 状态和接收字节数。遇到验证码跳转会在请求验证页之前停止，此时最后一跳的 `status` 为 `null`。运行时若未提供 `invocationId`，请另从云端调用记录抄下执行标识，不能把自填的 `requestId` 当成云端执行证明。

`structure.signals` 只记录标题、食材/步骤标记、JSON-LD Recipe、小红书初始状态及标题/正文键的有无；不执行网页脚本。`fingerprint` 是这些布尔信号的摘要，便于对比。标记可能出现在脚本或模板中：**`structure_detected`、`candidate=true` 和相同 fingerprint 都不能单独证明菜谱可解析或结构稳定**，也没有对小红书正文是否含做法作语义判断。

| outcome | 含义与处理 |
| --- | --- |
| `structure_detected` | 页面可返回且发现候选结构信号，仍需核对内容可用性 |
| `no_recipe_signals` | 收到 HTML，但未发现完整候选信号；可能是改版、登录壳或内容缺失 |
| `captcha` | 验证页特征或验证码跳转；停止，不尝试破解 |
| `forbidden` / `login_required` / `rate_limited` | 403 / 401 / 429；保留真实状态，不重试规避 |
| `http_error` | 其他非 2xx 状态 |
| `single_url_required` / `url_rejected` | 未找到唯一链接，或 URL 不符合限制 |
| `redirect_rejected` | 跳转到白名单外、另一个平台、HTTP 或带账号密码/非标准端口的地址 |
| `redirect_limit` / `invalid_redirect` | 超过 4 次跳转或缺少 Location |
| `dns_rejected` | DNS 无可用公网 IPv4，或混入内网/保留地址；不会建立连接 |
| `timeout` / `response_too_large` | 整个跳转流程超过 20 秒，或单页超过 1 MiB |
| `unsupported_content` / `unsupported_encoding` / `unsupported_charset` | 非 HTML，或响应未遵守 identity 编码，或字符集不受运行时支持；这是诊断器限制，不是平台拦截结论 |
| `network_error` | DNS、TLS、连接、响应截断等网络失败，不返回上游错误正文 |

每个实例每位管理员每分钟最多调用 5 次；这是临时诊断器的实例内限流，不是跨实例配额。请求使用明确的 `FamilyTableRecipeProbe/0.1.0` User-Agent，不伪装浏览器，不附带 Cookie、登录态或签名，不请求图片、脚本、视频等页面资源。

白名单仅包括下厨房、香哈、小红书的根域、`www`（下厨房、香哈额外允许 `m`）及 `xhslink.com` / `www.xhslink.com`。重定向只允许同一平台。遇到新的合法短链域名也会拒绝，应先审查再修改白名单。DNS 仅使用 IPv4，校验全部 A 记录后把公网地址固定到实际 TLS 连接；保留原始域名的 TLS 证书校验。

函数不写数据库，不记录分享文字、网页正文、上游异常、OPENID 或完整 URL。签名查询参数只用于内存中的当次请求，不在返回的跳转链中显示。不要把真实分享文字或令牌放进 `sampleId` / `requestId`，也不要将带令牌的测试事件或完整云日志提交到 Git / issue。

## 云端样例记录与首期判断

由运营者为三平台各选 2–3 个真实菜谱，尽量同时覆盖长链、短链及带多余文字的分享内容。不自行搜索其他页面。对相同样例在不同时间手动低频复测，遇到验证码或 403 即记录，不自动重试、不更换身份或请求头规避。

| 平台 | sampleId | 长链/短链 | 云端执行标识/环境/代码版本/时间 | outcome/各跳状态 | 耗时 | 结构信号及人工核对 | 是否可用 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 下厨房 | 待填写 | 待填写 | 待实测 | 待实测 | 待实测 | 待实测 | 未验证 |
| 香哈 | 待填写 | 待填写 | 待实测 | 待实测 | 待实测 | 待实测 | 未验证 |
| 小红书 | 待填写 | 待填写 | 待实测 | 待实测 | 待实测 | 待实测 | 未验证 |

分别报告 HTTP 可访问次数 / 总次数、结构信号命中次数 / 总次数，以及经内容核对后可用次数 / 总次数。验证码、403、登录壳、诊断器限制需分别计数，分母为 0 时写“未测试”。页面结构判断以多样例、多次记录为依据，不能只看一次 200 或一个 fingerprint。

下厨房、香哈需要后续确认标题、食材、步骤均可确定性提取；小红书需要确认可取得标题和正文，正文缺少做法时只能降级为粘贴文字/手动填写。本诊断函数只做前置网络和结构探测，不能替代后续解析器的内容验收。运营者反馈真实摘要后，再决定首期平台覆盖；暂不宣称支持任何平台。父任务历史本地 403/验证码记录不能计入云端统计。

## 离线测试

```bash
node --test tests/cloudfunctions/recipe-probe.test.js
node --test tests/**/*.test.js
```

测试使用合成 HTML 和模拟 DNS/HTTPS，不请求真实平台、不部署函数，验证身份边界、每跳 URL 校验、公网地址固定、验证码停止、超时、响应大小和敏感信息处理。离线测试通过不等同于云端抓取通过。
