## 验证

- TypeScript 5.9.3 编译通过，已同步首页 JavaScript。
- 129 项自动测试通过，覆盖投票权限、读取失败、重复菜品跨餐次、图片失败回退、默认昵称、空周菜单、导航避让、两张菜品插画映射及投票快照保留。
- 运行环境、数据库索引、开发环境代码检查通过。
- 模拟器验证真实首页、普通成员无投票、有候选菜、投票读取错误及“发起投票”跳转到创建表单；验证过程未创建投票或修改云端家庭数据。
- 在 390px 宽设备中，查看周菜单、查看清单的点击高度为 45px，发起投票为 47px，符合 88rpx 最小热区要求。
- 辅助文字与纸卡对比度 5.95:1，与页面底色对比度 5.25:1；采购副标题 6.89:1；未选中 Tab 5.90:1。
- 微信预览包成功生成，实际主包 2,095,615 字节，低于 2 MiB；余量仅 1,537 字节，后续增加素材应继续检查包体积。
- [首页预览](home-preview.jpg)；实机显示及不同系统的自定义导航仍需在新预览包中验收。
