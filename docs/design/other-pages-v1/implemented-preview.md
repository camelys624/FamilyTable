## 实现与验证

- 用公共插画组件裁切 4 × 3 图集，已知食材复用冰箱图集；未知菜品显示中性菜谱簿插画。用户上传图片优先展示。
- 保留现有分类、食材“用完／有剩”、AI 人工确认、批次选择、提交重试和版本冲突保护。做菜记录按钮按批次 ID 更新对应状态。
- 重构长表单与底部工具栏，设置安全区域间距；首次进入采用标准导航栏。修正原生按钮默认宽度与自定义组件插画尺寸造成的挤压。
- 补齐首页、菜谱列表和详情页的加载／错误显示；菜单成功重载后清除旧错误。
- TypeScript 编译通过；对应 JavaScript 同步。微信开发者工具 WXML／WXSS 编译检查通过。
- 67 项测试通过，包括新按钮对应批次、冻结后的原记录重试、插画映射及按需加载的页面组件声明检查。
- 修复全局插画组件在按需加载下出现的 `wx://not-found` 和“我的”页空白：消费页面均在自身 JSON 中显式声明组件，删除全局注册。重新编译打开后，“我的”页两个插画组件正常渲染，控制台没有组件缺失错误。
- 模拟器验证了搜索空结果、录入食材、用完／有剩切换、弹层打开与关闭，以及主要页面显示。
- 图片仅做 WebP 编码优化，尺寸与 alpha 通道保持一致；小程序源文件总量约 1.33 MB，实际上传包大小以开发者工具打包结果为准。
- 开发者工具仍有原先的基础库版本兼容提示；本次未修改基础库或开发者工具版本。
