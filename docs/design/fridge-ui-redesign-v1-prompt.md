## 生成提示词

Use case: ui-mockup. Create a polished, high fidelity redesign concept for the Chinese WeChat mini program refrigerator screen in the supplied screenshot. Input image 1 is the existing interface reference, not something to merely recolor. Deliver ONE refined design board containing exactly TWO front-facing portrait mobile screen mockups side by side: left is an illustrative stocked fridge state, right is the empty fridge state corresponding to the reference. Give the two mockups equal size, ample outer space, and only small Chinese state captions outside them: '库存示例' and '空状态'. The UI should be a convincingly buildable native WeChat interface, not a poster, not a dashboard, not a 3D sci-fi app.

Visual system: preserve the existing FamilyTable warm kitchen / handwritten recipe notebook identity. Very pale jade background #eaf2ea, creamy paper cards #fffdf7, dark forest ink #18332f, muted gray-green #718078, leaf accent #4f7a60, restrained butter-yellow #f4c95d for dates that need attention, thin pale borders #d7e1d8. Use expressive but readable Chinese Kai-style calligraphy only for the large main title; use precise modern Chinese sans-serif for all other UI copy. Gentle generous whitespace, rounded paper cards, soft subtle shadows, crisp understated line icons. A small, tasteful hand-drawn refrigerator with a couple of vegetables can add warmth, but should never dominate the content or compete with real controls. No heavy gradients, neon, glassmorphism, urgent red badges, giant pill shapes everywhere, or excessive decoration. All Chinese text must be clean and legible.

Keep the WeChat status bar, centered navigation title '家庭冰箱', and its top-right capsule controls. Preserve the five bottom navigation items, in this order: '今天', '周菜单', '菜谱库', '冰箱', '我的'. Use matching restrained outline icons and visibly select '冰箱' in leaf green. Do not include the old '购物' tab. The design should fully fit inside each screen and have a fixed bottom bar.

Information hierarchy and functions: simplify the reference's long administrative explanations, oversized equal-priority buttons, and flat section stacking. The hero uses the eyebrow '家的食材 · 好好珍惜', large title '打开冰箱', and one short friendly subtitle '看看家里还有什么，先吃临期的'. A clearly dominant action '+ 记一份食材' should be easy to reach. '刷新' is a small secondary icon-and-text action rather than another full-width primary button. Inventory is the visual center. The stocked-state mockup uses clearly illustrative sample content: an understated summary '6 批可用' and '2 批临期', a tidy inventory filter strip '全部' '临期' '有剩', and three beautiful compact rows inside one paper inventory card: '番茄' with '10月13日到期' and yellow '临期', '鸡蛋' with '10月18日到期' and green '有剩', '青菜' with '10月12日到期' and yellow '临期'. Each row has a small natural food illustration, a crisp text hierarchy, and a discreet chevron. Do not introduce grams, quantities, calorie metrics, shopping carts, safety guarantees, invented AI results, or extra features.

The empty-state mockup uses the same visual architecture but inventory summary '0 批可用'. Inside a spacious cream paper card, show a charming minimalist hand-drawn empty refrigerator and concise copy: title '冰箱还没记食材', supporting line '把家里剩下的放进来吧', and the strong button '+ 记第一份食材'. Keep secondary refresh understated.

Below the inventory area in both mockups, make a distinct, compact warm AI suggestion card with a subtle pan-and-vegetables drawing, title '冰箱里能做什么', small 'AI 建议' label, short supporting copy '用现有食材，想几道家常菜', and button '帮我想几道菜'. On the empty state, show this function in a calm disabled state with the supporting copy '记下食材后，再来想菜单'. Make it clear that suggestions are optional and require user action; do not show fabricated generated dishes. Finally include a minimal '食材变动记录' row with a small secondary '刷新记录' action and concise empty or latest-activity preview. Use the existing functionality only. The empty state can say '还没有食材变动'. Longer explanatory text from the reference should be reduced to one tiny secondary line '建议只供参考，做菜前再核对食材' near the AI card, not large blocks. Maintain comfortable mobile touch targets and realistic screen spacing. The result should feel like a thoughtful, premium but homely Chinese family cooking mini program, ready to guide a UI implementation.
